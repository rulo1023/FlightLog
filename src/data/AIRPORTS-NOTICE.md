# Catálogo local de aeropuertos

`airports.json` contiene una selección compacta de 6.071 aeropuertos con código IATA. Se generó el 16 de septiembre de 2026 combinando:

- [OpenFlights Airport Database](https://openflights.org/data.php), disponible bajo la [Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/1-0/). Se utilizan principalmente ciudad y país.
- [airport-data-js](https://github.com/aashishvanand/airport-data-js), disponible bajo [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Se utilizan nombre, códigos, coordenadas, país y zona horaria.

El archivo se distribuye junto a FlightLog para consultas locales. No se considera una fuente aeronáutica oficial y puede contener datos desactualizados o incompletos.
