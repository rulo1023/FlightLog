# Datos del mapa

`world-110m.json` contiene límites terrestres simplificados a partir de Natural Earth mediante `world-atlas` 2.0.2.

- Fuente: https://www.naturalearthdata.com/
- Distribución TopoJSON: https://github.com/topojson/world-atlas
- Escala: 1:110 millones
- Licencia de los datos de Natural Earth: dominio público

El archivo se incluye en la aplicación para dibujar costas y fronteras sin descargar mapas ni enviar el historial de vuelos a un proveedor externo.
